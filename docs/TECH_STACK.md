# Technology Stack - TTB Label Verification App

**Deployment:** Vercel (frontend + backend)

---

## Frontend (Essential)

- **Angular 19** (LTS) with TypeScript
- **TailwindCSS** for styling
- **@ngrx/signals** for state management
- **HttpClient** (built-in Angular)

---

## Backend (Essential)

- **Node.js 18+** with TypeScript
- **Express.js** for API
- **Tesseract.js** for OCR
- **Multer** for file uploads

---

## Optional (Add if time allows)

- **PrimeNG** - UI component library
- **@faker-js/faker** - Test data generation
- **Zod** - Schema validation
- **Winston** - Backend logging
- **Vitest** - Testing

---

## Why This Stack

- **Angular architecture** - Scalable and maintainable
- **Minimal backend dependencies** - Only essential libraries
- **TypeScript full-stack** - Share types between frontend/backend
- **Vercel-compatible** - Serverless deployment
- **Fast setup** - Complete in 1 day
- **No system dependencies** - Tesseract.js is pure JavaScript
